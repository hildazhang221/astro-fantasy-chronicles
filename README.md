# ✦ 星盘奇幻物语 · 异世界转生录 ✦
### Astro Fantasy Chronicles (日系治愈轻小说深度命盘版)

一个基于天文级星历算法与 AI 叙事引擎的**本命盘日系轻小说物语生成器**。

---

## 📖 项目简介 (Overview)

`astro-fantasy-chronicles` 能够将用户的出生日期与时间（例如 `2001.11.5 11:45`），通过精密星历计算出**八大核心星象落位**（太阳、月亮、上升、水星、金星、火星、木星、土星），并将其神话解构为主角的异界尊号、随身使魔、圣物与招式，自动生成一部 **1200 - 1600 字兼具温情治愈与日常冒险的日系轻小说史诗**。

---

## 🌟 核心特色 (Key Features)

- 🔬 **天文级高精度排盘**：基于 `PyEphem` 天文星历算法，精确计算黄道经度与宫位度数，确保排盘严谨真实。
- 🎭 **六大多元日系轻小说剧场**：根据命盘主导元素自动匹配最契合的世界观故事线：
  - 🏭 **【魔导工坊物语】**：奇物造物、破解失落机关与星空特调
  - ⛵ **【浮空海域航行】**：蒸汽飞空艇巡航、逆流巨浪与黄金天空岛
  - 📚 **【学院秘仪破谜】**：皇家图书馆禁书区、萤火文字重构与夜色长谈
  - 🌲 **【治愈森林巡礼】**：精灵古树地脉疗愈、百花绽放与自然祝福
  - ⚔️ **【先锋远征荣耀】**：边境要塞整备、双刃破障与王者英灵加冕
  - 🍲 **【深夜暖堂食堂】**：暖黄小酒馆、治愈心灵的神级流心料理
- 🎨 **视觉化多端输出**：
  - 🎴 **3:4 魔法塔罗执照卡**：粉金天使翼唯美古典排版，适合社交媒体分享。
  - 📜 **浑然一体羊皮纸长卷轴**：从执照、档案到四幕故事一气呵成的完整长图。
  - 📱 **交互式 HTML 网页**：支持手机端流畅左右滑动翻页阅读。
  - 🛠️ **高度可定制**：支持自定义个性化作者水印、署名与分享信息。

## 🚀 快速开始 (Quick Start)

### 方式 1：作为 AI Agent Skill
将本文件夹放置在你的 AI Skills 目录下，直接发送指令：
> `用星盘写小说，生日是 1991.3.29 21:45`

### 方式 2：Python 独立运行
```bash
# 安装依赖
pip install ephem pillow

# 执行计算与测试
python scripts/astro_calc.py
```
