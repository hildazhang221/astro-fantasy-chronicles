## 📖 项目简介 (Overview)

`astro-fantasy-chronicles` 是一个基于 AI Agent 与天文星历算法的**星盘奇幻轻小说生成器**。只需输入出生日期与时间（例如 `2001.11.5 11:45`），系统会自动计算**八大核心星象落位**（太阳、月亮、上升、水星、金星、火星、木星、土星），将其神话映射为主角专属的异界使魔、随身圣物、料理与招式，并一键生成包含 **1400字完整轻小说、3:4独立魔法执照卡、以及无缝羊皮纸长卷轴（带微信引流广告）**。

---

## 🌟 核心特色 (Key Features)

1. **🔬 天文级严谨排盘**：基于 `PyEphem` 算法，精确计算黄道经度至角分（Arcminutes），确保排盘 100% 真实无误。
2. **🎭 六大多元日系轻小说剧场**：告别单一打怪套路，根据命盘元素动态自适应：
   - 🏭 **【魔导工坊物语】**：破解失落机关器物与星空特饮
   - ⛵ **【浮空海域航行】**：蒸汽飞空艇巡航、逆流巨浪与黄金天空岛
   - 📚 **【学院秘仪破谜】**：皇家七层图书馆禁书区、萤火文字重构
   - 🌲 **【治愈森林巡礼】**：精灵古树地脉疗愈、百花绽放与草本软包
   - ⚔️ **【先锋远征荣耀】**：荒原边境要塞、双刃破障与王者加冕
   - 🍲 **【深夜暖堂食堂】**：暖黄小酒馆、治愈心灵的流心神级料理
3. **📦 全自动三件套交付**：
   - 🎴 **3:4 独立魔法塔罗执照卡**（粉金天使翼、高对比度大字、右上角带署名 `@霓居小圆`）
   - 📜 **浑然一体无缝长卷轴长图**（全长无断层羊皮纸，底部内嵌微信二维码与业务咨询）
   - 📱 **交互式 HTML 网页**（支持手机左右滑动翻页，随时随地优雅交付）

## 🚀 快速使用指南 (Quick Start)

### 方式 1：作为 Antigravity / Claude / Cursor 本地 Skill
将本文件夹放入你的 Skills 目录下（如 `~/.gemini/config/skills/astro-fantasy-chronicles` 或项目 `.skills/` 目录）。在对话框直接输入：
> `用星盘写小说，生日是 1991.3.29 21:45`

### 方式 2：Python 命令行批量生成
```bash
# 安装必要依赖
pip install ephem pillow

# 执行排盘计算与生成
python scripts/astro_calc.py
```
